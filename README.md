# PwdNote (密码与 API Key 保险箱)

> 简单易用、轻量快速的跨平台密码与开发者凭据管理工具。

专门为**账号密码**以及各大平台 **API Key / Token / 服务器凭据**打造，采用**零知识架构**与**系统底层加密**，在保障安全的同时，提供极其便捷的**一键复制明文**与**开发者快捷命令**体验。

---

## ✨ 核心特性

- **📋 极致便捷的复制体验**：
  - **一键快捷复制明文**：列表与详情页中，点击即可将密码、API Key 复制到系统剪贴板。
  - **眼球防窥切换**：默认掩码保护，点击眼睛图标一键切换查看真实明文字符。
  - **开发者专属快捷键**：针对 API Key 一键生成并复制 `export KEY="sk-..."` 环境变量与 `curl` 请求命令模板。
  - **剪贴板安全自动清理**：复制后 30 秒自动清空剪贴板，防止后台恶意进程偷取敏感凭据。
- **🔒 银行级零知识加密**：
  - **Argon2id**：抗暴力破解与 GPU 彩虹表攻击的主密码派生（KDF）。
  - **AES-256-GCM**：带完整性认证的高强度对称加密，数据落盘前全程密文，没有明文文件。
- **⚡ 轻量极速，跨平台支持**：
  - 基于 **Tauri 2.0 + Rust + React + Tailwind CSS**。
  - 内存占用仅几十 MB，启动秒开，原生支持 macOS、Windows 与 Linux。
- **🏷️ 便捷分类与即时搜索**：
  - 智能分类：API Keys、账号密码、服务器 SSH、安全备忘、星标收藏。
  - 标签系统（Tags）与即时模糊搜索。
- **💾 本地掌控与备份恢复**：
  - 数据文件完全归你所有（存储在本地 AppData 目录），支持一键导出带密码保护的单文件备份，可轻松放入 iCloud/网盘同步。

---

## 🛠️ 技术架构

- **底层安全层**：Rust (`aes-gcm`, `argon2`, `rand`, `zeroize`)
- **跨平台桥接**：Tauri 2.0
- **交互与界面**：React 19, TypeScript, Tailwind CSS, Lucide Icons
- **打包工具**：Vite

---

## 🚀 启动与运行

### 1. 安装依赖（已配置完成）
```bash
npm install
```

### 2. 启动桌面端开发模式
```bash
npm run tauri dev
```
首次运行会编译 Rust 依赖并启动带有热重载的桌面客户端窗口。

### 3. 打包发布安装包
```bash
npm run tauri build
```
打包完成后会在 `src-tauri/target/release/bundle/` 下生成当前系统的原生安装包：
- **macOS**：`.dmg` 或 `.app`
- **Windows**：`.msi` 或 `.exe`
- **Linux**：`.deb` 或 `.AppImage`
